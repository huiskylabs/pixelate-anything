# Library gallery

`pixelate gallery` generates the README card block, `docs/gallery/library.md`, this folder's static `index.html`, and managed `media/` copies for **every piece** in `library/index.json`. `pixelate gallery --check` compares them without writing or running piece code. Both reject stale catalog indexes. Maintainers may serve the HTML and thumbnails from `docs/` via GitHub Pages; this repo does not configure Pages deployment.

Each card shows the declared status, original request (or an honest note when it was not recorded), thumbnail and remix command. A card is **not** an art grade, approval, evidence of consent or a rights certificate. Review the [reference and font sources](SOURCES.md) and each contributed piece's provenance before accepting outside material; do not treat a manifest's `license` field as proof of third-party rights. The San Francisco reference was identified by the user as a Pexels photo not included here; Pixel Harbor reuses the first-party drawing program. The repo's MIT terms do not purport to relicense the unbundled photo.

`media/` is generated and managed by this tool; keep unrelated files elsewhere. Removing a piece from the catalog and regenerating removes its card and copied thumbnail. The generator reads bounded, no-follow thumbnail bytes and checks their file signatures; it does not decode them or run piece commands. PR CI must not invoke code supplied by an outside contributor: gallery generation, renders, tests and `library add` run only after a maintainer reviews and trusts the exact head, since piece commands have no sandbox.
